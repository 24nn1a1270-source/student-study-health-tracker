# 📚 Student Study & Health Tracker

A web-based student productivity and wellness tracker built using Python, Flask, and SQLite.

The application helps students manage their academic activities and daily wellness habits in one place.

## 🌐 Live Demo

👉 https://student-study-health-tracker.onrender.com

## ✨ Features

- 👤 Student profile management
- 📚 Study session tracking
- ✅ To-do task management
- 💧 Daily water intake tracking
- 🌱 Habit tracking
- 📊 Progress dashboard
- ✔️ Mark tasks and habits as completed
- 🗑️ Delete tasks and habits
- 🔄 Reset habits
- 💾 SQLite database integration
- 📱 Responsive web interface
